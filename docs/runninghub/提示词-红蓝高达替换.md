## 成稿之外、需要你定的事

1. **白刀要不要一并换掉**：源片两个角色都拿白色长刀，而 `<Picture 2>` 手里没有武器。现在没写道具句，模型大概率沿用源片的刀（打斗需要），但可能两边刀的样子不一致。要统一就在替换句后加一句，例如「角色手中的白色长刀替换为 `<Picture 1>` 中的金色能量光剑」。
2. **`<Picture 2>` 不是三视图卡**：它是单张正面渲染图，所以按「全身正面视角角色卡」写。如果背面/侧面会露，建议再补一张它的侧背图，加载位放第 3 位，提示词里相应补一句。
3. **视角取用句**：可以加「参考视频里角色正对镜头时用正面视角取外观，转成侧脸时用侧面视角取外观……」，多人打斗片里这一句有时反而打架，我没擅自加。
4. **帧数**：源片 416 帧 @30fps ≈ 333 帧 @24fps；工作流节点 193 的公式会取到 345 帧（14.375s），比源片长 0.5s，多出来的尾巴由模型补。工作流里有 347「计算吸附多出的尾帧」这条链在处理，先跑一次看落点是否满意。

## 自检

- 视觉内容（分辨率/帧率/时长/镜头结构/景别/运镜/风格）一句未重复；只保留「灰色摄影棚」「3DCG 质感」这类场景定性。
- 外观锚点各 6 项，全部「名词 + 主色」。
- 源片角色按衣着指认（红色装甲 / 蓝色装甲），未写源片人物的显著体征。
- 全篇正面描述，无否定句、无负面词表。
- 音频句固定「音频整轨 1:1 保留」；源片无水印，叠加层句省略。
